A project to detect misinformation using Large Language Models in an easy-to-use GUI program

How to setup the environment:
Just install Python and the google-genai package by running "pip install google-genai" in your terminal :-)

How to run the code and use the program:
Just run gemini_gui.py, input your API key, type in the statement you want checked, hit send, and then the results will be displayed
